# ชุดสีใหม่: น้ำเงินสด + ส้มอุ่น — Design (งานแก้เล็ก)

วันที่: 2026-11-18 · สถานะ: อนุมัติแล้ว (2026-11-18) · แทนที่ชุดสีของ `2026-11-17-colors-and-thai-size-design.md`

## ทำไม
เจ้าของกำหนดชุดสี 60-30-10 ใหม่ทั้งชุด สีน้ำเงินเป็นปุ่มหลัก ส้มอุ่นเป็นปุ่มรองและไฮไลต์ ขนาดตัวหนังสือและการจัดหน้าเหมือนเดิม

## เป้าหมาย / ไม่ทำ / ห้ามเกิด
- **เป้าหมาย:** ใช้สีที่เจ้าของกำหนดตามตำแหน่งในข้อ "ใช้สีกับอะไร"
- **ไม่ทำ:** ไม่เปลี่ยนขนาดตัวหนังสือ การจัดหน้า การทำงาน ข้อมูล หรือเสียงอ่าน และใช้ระยะขอบแถบหน้าแรกที่เจ้าของแก้เอง (`pt-3 pb-3`) ต่อ
- **ห้ามเกิด:**
  - ตัวหนังสือหรือไอคอนบนพื้นส้มเป็นสีขาว (ได้แค่ 2.1:1)
  - ตัวหนังสือสีส้มบนพื้นขาว
  - คู่สีใดต่ำกว่า WCAG AA (ตัวหนังสือ 4.5:1 ไอคอน 3:1)

## ทางเลือก (Approaches)
- **เปลี่ยนชื่อ token ใน `@theme` ให้ตรงกับหน้าที่ใหม่** (`page`, `primary`, `highlight` …) แล้วแก้คลาสใน `views.js` ให้ตรงกัน ← **เลือก** เพราะชื่อเดิม (`cream`, `accent` = ส้ม) จะทำให้คนอ่านโค้ดเข้าใจผิด
- เปลี่ยนแค่ค่าสีในชื่อเดิม: แก้น้อยกว่า แต่ `accent-strong` จะกลายเป็นสีน้ำเงิน และ `cream` เป็นเทา ทำให้งงตอนแก้ครั้งต่อไป

## ชุดสี (`@theme`)
| ชื่อ | ค่า | ที่มา |
|---|---|---|
| `page` | `#F8F9FA` | 60% พื้นหลัง (เจ้าของให้เลือก ขาว หรือ `#F8F9FA` → ผมเลือก `#F8F9FA` เพื่อให้การ์ดขาวแยกจากพื้น) |
| `ink` | `#222222` | 30% ตัวหนังสือหลัก (เจ้าของ) |
| `ink-soft` | `#6B7280` | ตัวหนังสือรอง (ผมเลือก ผ่าน 4.5:1 บน `page`) |
| `line` | `#E5E7EB` | เส้นขอบการ์ด (ผมเลือก) |
| `navy` | `#1E3A8A` | 30% หัวข้อ/แถบเมนู (เจ้าของ) |
| `navy-soft` | `#BFDBFE` | ตัวหนังสือรองบนแถบน้ำเงิน (ผมเลือก) |
| `primary` | `#2563EB` | 10% ปุ่มหลัก (เจ้าของ) |
| `highlight` | `#F59E0B` | 10% ปุ่มรอง/ไฮไลต์ (เจ้าของ) |

การ์ดยังเป็นพื้นขาว (`bg-white`)

## ใช้สีกับอะไร
- **ทั้งหน้า:**
  - พื้นหลัง `page` ตัวหนังสือ `ink`
  - `theme-color` และพื้น favicon เป็น `#1E3A8A`
- **แถบเมนูทั้งสองหน้า:**
  - พื้น `navy` ตัวหนังสือขาว
  - บรรทัดรองสี `navy-soft`
- **หน้าแรก:**
  - **ป้ายเลข 01–04:** พื้น `highlight` ตัวเลข `ink` (ป้ายสี่เหลี่ยมมุมมน)
  - **ลูกศร:** `primary`
  - **ตอนชี้หรือกดการ์ด:** ขอบการ์ดเปลี่ยนเป็น `primary`
- **หน้าหมวด:**
  - **พินอิน:** `navy`
  - **ปุ่มลำโพงทั้งสองปุ่ม (อังกฤษและจีน):**
    - **ปกติ:** วงกลมพื้น `highlight` ไอคอน `ink` (เจ้าของกำหนด: "ปุ่มลำโพงใช้ #F59E0B ทั้งคู่ ไม่แยกสี")
    - **ตอนกำลังอ่าน:** วงกลมเปลี่ยนเป็น `navy` ไอคอนขาว ให้รู้ว่ากำลังเล่น (ผมเลือก)
  - **ปุ่ม "หมวดถัดไป" (ปุ่มหลัก):** พื้น `primary` ตัวหนังสือขาว เมื่อกดเปลี่ยนเป็น `navy`
  - **ปุ่ม "← หน้าแรก" และ "กลับหน้าแรก" (ปุ่มรอง):** พื้น `highlight` ตัวหนังสือ `ink` ไม่มีเส้นขอบ

## การทดสอบ
- **`tests/theme.test.js`:** ตรวจว่ามีครบ 8 สีตามตาราง และตรวจคู่สีต่อไปนี้
  - **ตัวหนังสือ ≥ 4.5:**
    - ink บน page และบนขาว
    - ink-soft บน page และบนขาว
    - ขาวบน navy
    - navy-soft บน navy
    - navy บนขาว
    - ขาวบน primary
    - ink บน highlight
  - **ไอคอน ≥ 3:**
    - primary บนขาว (ลูกศร)
    - ink บน highlight (ลำโพง)
    - ขาวบน navy (ลำโพงตอนกำลังอ่าน)
- **`tests/views.test.js`:**
  - เช็คสีจากธีมเปลี่ยนเป็นชื่อใหม่
  - ไม่มีคลาส `cream`, `accent` หรือ `accent-strong` เหลืออยู่
- **`check.py`:** สีที่วัดได้จริงต้องเป็นดังนี้
  - `body` = `rgb(248, 249, 250)`
  - แถบด้านบน = `rgb(30, 58, 138)`
  - วงกลมลำโพงตอนปกติ = `rgb(245, 158, 11)`
  - วงกลมลำโพงตอนกำลังอ่าน = `rgb(30, 58, 138)`
  - `theme-color` = `#1E3A8A`
  - การตรวจเดิมทั้งหมดยังต้องผ่าน

## แก้ตามเจ้าของ (2026-11-18, ก่อนเริ่มทำ)
- **ตอนปุ่มลำโพงกำลังอ่าน:** ไม่ต้องเป็นน้ำเงินเข้ม ให้ใช้ "ส้มที่เข้มกว่านิดนึง" แทน
  - เพิ่ม token `highlight-strong` = `#D97706`
  - `.speak-btn.is-speaking > span` ใช้ `background-color: var(--color-highlight-strong)` ไอคอนยังเป็น `ink`
  - ink บน highlight-strong ได้ 5.0:1
- **ตัวเลขที่ใช้ตรวจเปลี่ยนตาม:**
  - `theme.test.js` ต้องมี 9 สี (เพิ่ม `highlight-strong`) และตรวจไอคอน ink บน highlight-strong ≥ 3
  - `check.py` ตรวจว่าวงกลมตอนกำลังอ่านเป็น `rgb(217, 119, 6)` และไอคอนเป็น `rgb(34, 34, 34)`
